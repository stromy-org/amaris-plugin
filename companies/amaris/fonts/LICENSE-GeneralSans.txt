is NOT an SIL Open Font License family. Its terms are the Fontshare / ITF free
font licence, published at the URL the font itself carries.

The notice below is reproduced verbatim from the shipped binaries' OpenType name
table, which is the authoritative licence notice the foundry attached to these
bytes. It is recorded here rather than as a copy of the terms page, because
https://www.fontshare.com/terms is a JavaScript application with no
server-rendered text: a scraped copy could not be verified and would rot
silently. The notice below can be re-derived from any GeneralSans-*.otf/.ttf in
this directory at any time:

    python3 -c "from fontTools.ttLib import TTFont; n=TTFont('fonts/otf/GeneralSans-Regular.otf')['name']; print(n.getDebugName(0)); print(n.getDebugName(13)); print(n.getDebugName(14))"
